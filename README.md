# CurrencyWarsLegacy

A browser-based website. Plain HTML, CSS, and JavaScript — no build step, works in any modern browser.

## Files

- `index.html` — markup
- `style.css` — styles
- `script.js` — behavior

## Run locally

Just open `index.html` in a browser, or serve it:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000
